My agent got ONE prompt. It built this ghost-catching game — Ghost Catcher, a tiny browser game — and the video shows the prompt, the agent at work, and the finished game running, ending on make.fun's referral end card. The judged entry is the X post itself (its address is in POST.json); this program just hands the house the post's address, the video, and the game, byte for byte.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
